# bordalofelipe.github.io

Portfólio pessoal de Felipe Bordalo: https://bordalofelipe.github.io

Site estático em um único `index.html` (HTML e CSS, sem dependências).

## Como ver localmente

1. Baixe o repositório:

   ```bash
   git clone https://github.com/bordalofelipe/bordalofelipe.github.io.git
   ```

   Ou use **Code > Download ZIP** na página do repositório e extraia a pasta.

2. Abra o `index.html` no navegador.

## Publicação

O site é publicado pelo GitHub Pages a partir da branch `main`.
